# FocusSpace 全站 UI/UX 检查与优化

日期：2026-09-09

## 依据与设计方向

依据产品需求文档 PRD v1.0、开发设计文档及已落地的阶段增量，覆盖登录、注册、首页、公开房间、邀请、大厅、专注、休息、结算、历史、个人资料、管理员五个栏目及异常入口。

沿用湖蓝导航、浅色纸张面板与房间原有的木色/阅读灯主题。以 PRD 的“共同节奏、他人在场、任务推进、低干扰交流”为设计准则。共享色彩、响应式和控件规则集中于 `apps/web/src/experience.css`；房间主题继续由既有场景系统控制。

检查同时参考 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md) 的键盘可用性、表单标签、状态反馈、减少动态和响应式原则。

## 检查结果与落地修改

| 页面/交互 | 问题 | 已实现的优化 |
| --- | --- | --- |
| 全站导航 | 历史入口不明显；页面标题固定；键盘缺少跳过导航入口 | 增加首页/历史导航和当前位置样式、路由标题、跳到主要内容链接 |
| 登录/注册 | 密码无法核对；管理员与带筛选参数的回跳会丢失目标 | 显示/隐藏密码；账号禁止自动大写与拼写检查；保留合法站内目标及参数；昵称空白校验 |
| 首页 | 偏好说明占据主流程；技术文案较多 | 创建/加入面板分层；常用节奏按需展开；简化说明；房间名称与房间码格式校验 |
| 公开房间 | 筛选无法刷新恢复；无结果缺少后续动作 | 筛选/页码写入 URL；支持清除筛选；空房间引导创建；单页不显示无效翻页控件；主题卡片统一布局 |
| 邀请页 | 房间码缺乏层级，操作说明偏实现细节 | 邀请凭条样式、突出房间码、精简入座说明、阻止重复提交 |
| 大厅/专注 | 任务操作挤压标题；房主管理常驻干扰；成功使用错误样式 | 任务标题与操作分行；管理区默认收起；独立成功提示；准备/暂离具有按下状态语义 |
| 休息 | 专注视图不会随阶段自动显示聊天 | 进入休息自动展开、回到专注自动收起；保留手动展开/收起；精简本轮反馈文案 |
| 任务/聊天 | 提交处理缺少局部重入保护 | 增加忙碌/禁用/阶段/空内容检查，继续由服务端确认状态与权限 |
| 结算 | 保存结果页重复链接到自己；结束后仍显示失效的准备/暂离区 | 保存页转到历史；清理结束后的失效操作；独立总结页标题与指标层级 |
| 历史 | 累计数据集中在一段长文本中；页码无法恢复 | 四项累计指标；独立一级标题；空状态行动入口；页码写入 URL |
| 管理后台 | 栏目/查询刷新后丢失；移动表格不便键盘滚动 | 栏目使用真实链接；查询/页码保留于 URL；表格可聚焦滚动；统一指标、卡片、确认与成功反馈 |
| 全站弹窗 | 关闭后焦点未可靠回到触发按钮 | 统一 Modal 生命周期；原生模态焦点约束；关闭/卸载时恢复触发位置；保存期间限制关闭 |
| 退出登录 | 浏览器原生长段确认难以阅读 | 页面内确认弹窗，区分继续与退出，展示处理中/失败状态 |
| 加载与移动端 | 房间/后台随入口加载；窄屏控件与长文本缺乏统一约束 | 房间/后台按需加载；控件、长内容、对话框高度、安全区、减少动态统一处理 |
| 静止 3D 场景 | 减少动态模式下，视口变化后捕获到空白画布 | 保留最后绘制帧；继续保持按需绘制和离屏暂停，验证窄屏画布包含实际场景像素 |
