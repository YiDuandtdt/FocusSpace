# FocusSpace 计划、统计与排行榜阶段交付

## 用户入口

- `/todos`：创建待办，设置优先级、截止日期、标签、日程、子任务和每日/每周重复；在清单与月历间切换。
- `/analytics`：切换日、周、月，查看有效专注趋势、上一周期对比、标签饼图、任务明细和近十二周热力图。
- `/leaderboard`：查看本周有效专注时长榜与成长等级榜。
- `/` 与房间大厅：创建或修改节奏时选择目标轮数；“无限轮”持续循环并由房主手动结束。
- 房间“我的任务”右上角“从清单加入”：多选待办加入本场；之后任一端勾选或取消，另一端同步更新。房间新建任务的“设置”中可指定上级任务、优先级、截止日期和标签。

## 数据和结算规则

待办是跨场次长期保存的计划，房间任务属于单场共学。同一待办在同一场只创建一个关联任务，导入请求具备服务端幂等记录。父任务删除会连同房间子任务删除；待办删除归档整个子树。重复任务在完成转换时建立下一日期实例。

统计和本周专注榜只读取已结算的正式 StudyRecord，45/15 秒演示不计入。单场任务并未分别计时，因此任务和标签的专注秒数按本场任务数均分，用于方向性复盘；总有效专注仍以服务端参与区间为准。等级榜读取服务端成长账户，不提供额外收益。

固定轮数在最后一轮 Focus 完成时由服务端自动结束、保存学习记录并执行原奖励结算。刷新、断线或进程恢复通过持久化的阶段边界继续处理。旧房间 targetRounds 为空，沿用无限轮行为。

## 验证

```powershell
npm run typecheck
npm run build
npm run test:planning
npm run test:planning-ui
```

`test:planning` 使用临时数据库和可控时钟，验证清单层级、幂等导入、双向进度、重复实例、固定轮数自动结束、StudyRecord、统计及排行榜。`test:planning-ui` 在临时数据库和隔离端口启动生产构建，使用本机 Edge 验证导航、待办创建、日历、统计、排行榜、无限轮和房间导入，不写入正式账户。

## 当前限制

- 每个账号最多保留 10000 项未归档待办；每场每人最多 100 个房间任务；标签每项最多 8 个。
- 重复方式为每日或每周，不包含复杂的每月规则、跳过节假日和自定义 RRULE。
- 日历提供月视图并按日程开始或截止日期定位，不提供拖拽改期和外部日历同步。
- 统计不追溯构造旧记录缺少的任务属性；排行榜当前最多显示 50 人。
- 房间任务同步的是完成状态；标题、标签和日期在加入后分别保存，避免修改长期待办时改写正在进行的共学快照。
