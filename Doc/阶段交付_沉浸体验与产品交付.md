# 第七阶段：沉浸体验与产品交付

沿用已完成的共学、任务、聊天、反馈、公开房间、管理员系统及 Three.js 房间/Avatar，只增加空间主题和个人体验状态。

## 体验入口与更新

在项目根目录执行：

```powershell
npm ci
npm run setup
npm run build
npm run start:local
```

本机入口为 [http://localhost:3002](http://localhost:3002)。登录后新建或返回房间，在大厅选择主题，开始共学后点击「专注视图」或「全屏专注」。开发入口仍为 `npm run dev` 后的 [http://localhost:5173](http://localhost:5173)。房间深链接 `/rooms/:roomId` 保持不变。

已有数据更新前先运行 `npm run db:backup`。新增迁移 `20260909000000_room_theme` 只为 Room 添加 `theme`，旧房间默认 `rain`；使用 `setup` 或 `db:deploy` 应用迁移，不重置数据库。部署仍使用现有单实例方式，网络部署沿用原有说明。

## 已实现

| 空间 | 外观差异 | 个人声音推荐 |
| --- | --- | --- |
| 窗边雨天 | 灰蓝窗景、冷柔天光、鼠尾草绿地毯，少量缓慢雨线 | 窗边雨声 |
| 暖灯夜读 | 深蓝夜窗、小月亮、暖色桌灯、较低环境光 | 炉火轻响 |
| 明亮图书馆 | 浅木桌面、明亮日光、浅绿地毯、书架叠书 | 林间鸟鸣 |

- 房主在大厅选择，服务端校验主题枚举、房主身份及大厅阶段，通过现有房间快照同步。刷新/重连从数据库恢复。开始后固定；切换主题不清除准备、不重置节奏。公开房间卡片显示相同主题名称；公开目录沿用主动刷新，返回目录后读取最新信息。
- 四条真实录音：窗边雨声、炉火轻响、林间鸟鸣、溪水潺潺。播放/暂停、取消加载、选择、循环、音量均可用；声音和音量按账号保存到当前浏览器。主题只显示建议，不主动换曲或改变播放状态。
- 默认无声音、无音频请求。只有点击播放才加载所选 MP3；播放中主动选另一种声音会继续播放，暂停中选声仍暂停且不预加载。失败显示明确错误，可重新播放或换声；离开页面、共学结束会暂停并释放音频源。
- 专注视图收起房间介绍、邀请、主题选择、成员统计、管理和节奏说明，保留倒计时、空间、任务、音频、暂离及结束/退出；聊天可主动展开，仍遵循原有休息阶段权限。显式「返回完整界面」恢复所有操作。房主要转交后离开时先返回完整界面。
- 桌面支持 Fullscreen API、退出按钮和浏览器原生退出；浏览器拒绝或不支持时留在普通专注视图。收到结束状态时显示结算并退出全屏。视图切换不卸载房间订阅、任务或播放器，不清除草稿。
- 复用 Avatar 专注/休息/暂离/断线姿态，任务完成时对应座位出现一次轻量文字/底色提示，不显示私有任务标题。雨线和 Avatar 轻微动态遵循系统 `prefers-reduced-motion` 或本机「减少动态」开关；关闭动态后只按状态更新重绘，无持续闪烁。
- 保留 3D/卡片切换、按需加载 Three.js、WebGL/异步代码加载失败降级与重试；页面隐藏或场景滚出视野时停止渲染，销毁时释放 GPU、监听器、观察器和音频。
- 手机可用任务/聊天/声音快捷入口；控件至少 44px，输入字号 16px，长任务换行。支持 320px 窄屏及横竖屏变化；VisualViewport 更新可视高度、键盘出现时滚动输入区域并取消遮挡输入的粘性导航；对话框限制在可视高度内且可滚动。

## 资源与体积

四条 MP3 各 22 秒、44.1 kHz 双声道、96 kbps，每条 264,926 字节，新音频总计约 1.01 MiB。已做响度规范化和 2 秒首尾交叉淡化。旧合成 WAV（约 2.20 MiB）仅为兼容旧页面保留，新声音菜单不加载它。无新增外部模型、纹理或字体；场景仍使用现有简单几何体，DPR 上限 1.5、动态渲染上限 30 fps。

雨声为 alex36917 的 CC BY 4.0 录音，鸟鸣和溪水为 CC0，炉火由原作者声明 Public Domain。逐条原作者、来源、许可、上游固定提交及修改记录见 [资源来源与授权](资源来源与授权.md) 和 [随应用分发的音频 SOURCES](../apps/web/public/audio/SOURCES.md)；输入/输出 SHA-256 见 `manifest.json`。没有缺失录音或静音占位。

## 两人演示路线

1. 两个独立浏览器登录；A 创建公开房间，B 加入。在大厅逐个选择三种主题，观察窗景、光色、两端主题名和公开目录卡片。B 无主题修改权限。
2. A 播放雨声并调低音量，B 保持静音；A 换夜读主题，确认雨声继续且不自动换炉火。分别试听四种声音，暂停后换声保持暂停。
3. 各建一项任务并准备，开始共学。主题选择收起，房间主题固定。写一段未提交任务草稿，切换专注/完整视图，确认草稿和倒计时连续。
4. 桌面进入全屏，再用退出按钮或 Esc 返回；在不支持的浏览器使用普通专注视图。切换减少动态、3D/卡片，计时和成员位置保持一致。完成任务，观察对应座位的轻量提示。
5. 手机通过「我的任务」「声音」「休息聊天」操作。长任务、500 字聊天、旋转屏幕及输入键盘场景中，可以滚动到提交按钮和退出操作。聊天只在 Break 开放，专注视图可展开再收起。
6. 在专注视图结束共学，确认自动显示结果、音频停止、全屏退出；查看已有学习记录。再次进入房间保留声音选择/音量/视图偏好，但不会自动播放。

快速演示仍可使用已提供的 45/15 秒节奏（需 `DEMO_MODE=true`），不新增独立计时或假结算路径。

- 偏好只保存在当前浏览器、按账号区分，不跨设备；存储不可用时显示提示并保留本页操作结果。全屏不自动恢复；进入页面不会自动播放。
- 公开目录按原有主动刷新更新主题，房间内实时同步。弱设备可选择座位卡片；没有基于模拟器帧率作大规模性能重构。
