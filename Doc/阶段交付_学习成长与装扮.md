# 学习成长与装扮（2026-09-10）

## 体验入口

- 正式用户：首页「成长与装扮」或 `/growth`；个人空间 `/space`；结束后 `/sessions/:sessionId/summary`。
- 管理员：现有 `/admin` →「成长、物品与补偿流水」→ `/admin/growth`。使用原 `npm run admin:init` 建立管理员，普通用户无权访问管理数据或提交修改。
- 成长页显示等级进度、币余额、最近 20 笔流水、下一步目标、规则说明与可筛选物品架；点击物品使用相同生成器预览。兑换后可直接使用或进入个人空间。
- 个人空间区分待获取内容。卸下回到同槽基础搭配；拥有资产不被消耗。共学房间保留发起时的空间快照，角色使用自己的装备。

## 初始规则 v1

| 来源 | 条件与上限 | 经验 | 学习币 |
|---|---|---:|---:|
| 有效专注 | 服务端有效整分钟；重叠标签合并 | 每分钟 2 | 每分钟 1 |
| 完整轮次 | 沿用完整参与；本场每 25 有效分钟最多一次 | 5 | 2 |
| 学习目标 | 开始前创建、结束前完成，且有效专注 ≥ 5 分钟；每日一次 | 5 | 2 |
| 共学 | 与他人有效重叠 ≥ 5 分钟；每日一次 | 5 | 2 |

整场结束统一到账，目标与共学各按北京时间结算日限一次。跨日不丢时长，不重复给每日奖励；不足整分钟余数本场不发币。提前离开会保留有效参与，等待该场最终结束后到账。AFK 和断线期间不记录有效学习，也不扣经验或降级。

Lv.2 需要 100 经验，Lv.3 需要 400，之后按 `100 × (等级-1)²`。等级没有消费用途。初次 5 分钟有效专注获得 10 经验 / 5 币，可兑换陶红开衫或一束小花；若符合首次目标条件，还会增加 5 经验 / 2 币。一个完整 25 分钟轮次的基础 + 轮次为 55 经验 / 27 币，目标及共学都符合时为 65 / 31。

## 管理员操作

从已实现目录选择资源，填写价格、最低等级、启用 / 下架 / 停用及原因后保存。基础资源不能设价、设等级或停用。普通下架仅停止新获取；停用则在个人空间和房间显示同槽基础替代，资产拥有权保留。

按用户 ID 查询账户、资产与分页流水；用户 ID 可在原用户管理页复制。补发经验（非负）、补发币、负币纠错或指定资产补发必须填写原因，操作同时保存补偿流水和审计。余额不能为负；没有无记录直接改余额入口。相同请求重试不会重复补发。规则发布自动生成下一版本，只影响之后创建的 Session，历史流水不重算。查看操作详情使用原「操作审计」。

## 可复现短演示

1. 在项目根目录执行 `npm run build`，再 `npm run demo:growth`。
2. 脚本创建新的 `.tmp/growth-demo-*` 数据库，打印 `growth_demo` / `growth_admin` 的随机密码及路径；只绑定 `http://127.0.0.2:4319`，不会读取正式 DATABASE_URL，浏览器主机名也与 localhost 的正式登录隔离。
3. 用 growth_demo 登录，打开 `/sessions/demo-growth-study/summary`，查看按可控时间产生的已到账经验、币和 Lv.2 新开放内容；全局提示明确标记隔离演示。
4. 到 `/growth` 预览并兑换 5 币花束，点击使用，再到 `/space` 查看。领取 Lv.2 休息伸展并查看休息状态；回首页创建单人房间或复制邀请链接共学。45/15 演示节奏本身仍不发正式奖励。
5. 退出登录，使用 growth_admin 打开 `/admin/growth`，查询用户 ID `growth_demo`；填写原因补发 2 币，然后查看流水与 `/admin?tab=audits`。可以下架刚兑换的物品，验证已拥有仍能使用。
6. Ctrl+C 停止演示。重跑命令创建另一个全新数据库，不会将演示数据同步到正式账户。服务器没有可控制时间或批量发币的公开 API。

## 具体限制

- 部署沿用单 Node 写队列 + SQLite，未支持多个进程同时操作同一数据库。
- 奖励按整场结算，提前离开不会即时到账；进行中的房间没有实时发币。事务失败会回滚本次结束，需要重试或重启恢复；确有 PENDING 的已结束记录会在启动 / 成长页读取时补偿。
- 经验不能负向纠错；币纠错不能产生负余额。每日奖使用北京时间固定日界线；不是按用户所在地动态切换。
- 普通用户展示最近 20 笔流水，管理员可分页查看全部；未做复杂账单搜索、下载或任务平台。
- 声音允许目录试听，静态音频预览不是 DRM；保存环境音装备和正式播放接口均校验资格。
- 已有生成器与槽位数量有限，不提供通用建模、任意脚本、自由摆放或上传 3D 资产。
- Three.js 相关懒加载包存在约 511 kB 构建体积提示，未开展无关大规模优化。
