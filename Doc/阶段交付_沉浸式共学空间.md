# 第三阶段：沉浸式共学空间

依据 PRD 5.6、5.7、6.2–6.5 与开发设计文档 6.1–6.3 增量实现。沿用前两阶段的服务端成员状态、统一节奏、AFK 与断线统计、私人任务和公开进度、BREAK 聊天、持久化 Summary；没有修改服务端、共享契约或数据库结构。

## 启动与入口

项目根目录执行 `npm ci` → `npm run setup` → `npm run dev`，打开 <http://localhost:5173>。从现有首页创建、加入或继续房间，`/rooms/:roomId` 自动加载空间。已有第二阶段数据保留；本阶段不增加迁移。生产启动为 `npm run build` 后 `npm start`，访问 <http://localhost:3001>。

需要快速观察阶段变化时，沿用 `.env` 的 `DEMO_MODE=true` 和房主的 45/15 秒演示节奏。两个独立浏览器登录不同账号，共同准备并开始；依次观察伏案、伸展、休息聊天室展开，再结束查看原有结果。

## 可体验效果

- 单一窗边自习室：固定正交视角，暖木长桌、八把绿色座椅、两盏台灯、窗框、书架与植物；均由简单几何体及粗糙材质构成。
- 四种头像复用 `lake / sage / lilac / sun`，分别表现为耳机、嫩芽帽、贝雷帽与鸭舌帽，配合不同服装颜色；不新增角色选择入口。
- 状态姿态：JOINED 坐着轻呼吸；READY 举手；FOCUSING 前倾、低头并轻微书写；BREAKING 后仰伸展；AFK 隐去身体、保留空椅与离席文字；DISCONNECTED 半透明、低头、虚线标签；ENDED 回到安静坐姿并显示结束。
- 所有座位显示编号、昵称与文字状态。服务端 `seatIndex` 是唯一位置来源，客户端不排序分座。刷新、短时断线保留座位；主动离开释放原座位，新成员使用服务端分配的空席，其余成员位置不变。主动退出后再加入不承诺取回已被占用的旧席。
- Focus 的大号倒计时与场景构成主区，Break 柔和改变背景与日光强度，配合原有聊天展开；任务始终保留独立入口。桌面右侧操作，手机单列与吸顶快捷入口；成员列表在面板内滚动。
- 雨声默认关闭，点击后播放本地循环 WAV，支持暂停与 0–100% 音量；其他成员不受影响。加载失败显示提示并允许再次播放；不把失败当作播放成功。房间结束或离开页面停止并释放音频。
- Summary 仅统一为绿灰与浅色面板，继续消费现有统计数据和持久化查询。

## 模块边界

| 文件 | 职责 |
| --- | --- |
| `apps/web/src/features/space/StudySpace.tsx` | React 容器、动态导入、加载/失败/主动卡片模式及重试 |
| `StudyRoomScene.ts` | 固定场景、家具、服务端成员对象更新、DOM 座位标签、渲染生命周期 |
| `AvatarModel.ts` | 四种几何体角色、状态姿态与纯视觉动画；`root / update / animate / dispose` 可由后续 GLB 实现替换 |
| `geometry.ts` | 单个场景/角色范围内共享简单几何体与材质，并统一释放 |
| `memberPresentation.ts` | 固定物理座位、状态中文标签与符号 |
| `space.css` | 房间响应式布局、座位标签、降级卡片及音频样式 |
| `apps/web/src/features/audio/AmbientAudio.tsx` | HTMLAudioElement 生命周期、真实播放事件、用户点击、音量与错误反馈 |
| `scripts/generate-ambience.mjs` | 可复现的原创雨声生成与循环接缝交叉淡化 |

3D 的输入只有 `members / phase / userId`，没有 Socket、业务命令、专注计时器或状态机。`requestAnimationFrame` 时间只控制轻运动和场景过渡，倒计时仍使用现有 `PhaseTimer` 与 `useRoom` 的服务端校准时间。后台恢复后的业务同步仍由既有 `useRoom` 负责。

## 性能、释放与降级

Three.js 独立动态代码块，仅进入房间时加载。像素比上限 1.5，渲染上限 30 FPS，半球光与一盏方向光，无实时阴影、后处理、粒子或外部纹理；台灯仅用发光材质。家具复用三种几何体和颜色材质，角色独立持有少量共享资源。

每帧只更新 Three.js 对象，不触发 React 更新。`visibilitychange` 与 `IntersectionObserver` 在页面隐藏或场景离屏时停止动画帧；数据仍可更新，恢复显示最新状态。`prefers-reduced-motion` 时取消持续动画，只在状态/尺寸变化时绘制。离开、切换卡片或失败时取消动画帧、解除观察器和监听、释放几何体/材质/renderer 与 WebGL 上下文，并移除 canvas 和 DOM 标签。

WebGL 不可用、动态脚本加载失败、15 秒加载超时、shader/渲染异常或 context lost 均降级为同一份服务端数据的八席卡片。容器通过异步加载与渲染异常回调隔离故障，任务、聊天、计时不依赖场景成功。用户可主动切换卡片节省资源，或重试创建 3D。若部署更新后旧脚本文件已被删除，应刷新页面加载新版入口。

相关 API 依据：[Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[Three.js 资源释放](https://threejs.org/manual/en/cleanup.html)。

## 验证入口与具体限制

执行 `npm run typecheck`、`npm run build`、`npm run test:space`；回归既有多人闭环使用 `npm run test:session`。测试使用各自 `.tmp` 隔离数据库与空闲端口，不修改日常数据库。`test:space` 会保存八人、Focus、Break、桌面/手机与降级截图，检查姿态、稳定座位、真实音频播放进度/循环、隐藏渲染暂停、资源释放及故障后的业务可操作性。故障测试通过测试侧注入，不暴露生产测试入口。

本次结果（2026-09-08）：类型检查、生产构建、`test:space` 与 `test:session` 均通过；已查看八人桌面和 390px 移动截图并修正相机裁切、标签拥挤和成员面板宽度。最终场景截图位于 `.tmp/space-kK1uQ9`，原有完整闭环截图位于 `.tmp/session-DZnyny`（仅本地验证产物，不随 Git 提交）。Three.js 场景代码块生产 gzip 约 123 kB；雨声实际 RMS 0.130、峰值 0.580，浏览器验证正常推进播放时间及跨循环边界，未做真人听感评分或实体设备帧率基准测试。

限制：

- 仅一个空间、四种基础几何体形象；不支持自由移动、碰撞、商城、多主题或高级角色定制，暂未使用 GLB/glTF。
- 需要 WebGL 2；不支持时只有成员卡片。自动验证使用桌面 Edge 与 390px 移动视口，并非实体手机 GPU 测试；尚未实测低端设备、Safari/iOS 的帧率、后台音频与音量策略。
- 手机 3D 标签空间有限，长昵称省略；完整昵称和状态在成员列表/卡片中可查看。
- 仅一段程序合成雨声，未做自然录音替换；播放与音量不持久化，刷新默认为关闭，移动系统可能暂停后台音频。隐藏页面本身不主动停止用户已选择播放的声音。
- 维持单实例、最多八人和前两阶段既有统计、聊天历史及重连宽限限制，不扩大业务范围。
