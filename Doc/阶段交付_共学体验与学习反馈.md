# 第五阶段：共学体验与学习反馈

完成日期：2026-09-08。简要核对 PRD v1.0 与开发设计，复用已完成四阶段的身份、房间、阶段推进、参与区间、事务幂等和恢复机制。本文件是 PRD 的本阶段增量规则，优先于原文按 Day 排期及 P1 延后表述。

## 体验入口与实际增量

首页 `/` 提供默认新建节奏保存、最近三条已结算记录及 `/history` 入口；历史每页 10 条，有正式累计场次、有效专注、完整轮次和任务数，可进入原 `/sessions/:id/summary`。历史身份始终来自认证会话，不能通过传 userId 查询其他人。无已保存结算的旧场次不列入历史，直接访问旧 Summary 会标明结算不可还原。

房间 `/rooms/:id` 保留现有视觉、3D 和卡片。修复节奏保存失败仍收起；删除需确认；Start 显示未连接、暂离、未准备等原因；退出登录说明本会话断开、房主宽限后结束全房及普通成员释放座位的影响。

邀请链接 `/join/:code` 与房间码并存。未登录先登录/注册，成功后回原邀请页，由用户点击加入；使用同一服务端加入流程，检查已有房间、成员资格、容量、结束状态。加入前推进过期阶段及房主超时状态，链接不直接授予座位。

原有规则已经实现并继续保留：任务可在 Lobby、Focus、Break 新建和编辑；中途加入立即同步当前阶段，从有效连接时刻计个人参与；多标签不重复计算，AFK、断线和停机不补记专注。

## 偏好、草稿与隐私

- 默认节奏、音量、3D/卡片选择存 localStorage，版本化且按账号 ID 隔离；仅同浏览器可复用。节奏只初始化新建表单，加入房间不会写共享设置。音频播放状态不保存，进入或刷新始终要求主动播放。
- 新任务、编辑标题（含原版本）、聊天草稿及未确认请求 ID 存 sessionStorage，按账号、房间隔离，24 小时到期，刷新或同标签页返回可恢复。浏览器关闭标签页通常清除；无跨设备同步。版本冲突保留编辑内容并要求重新核对。
- 退出/鉴权失效清理草稿；跨标签退出事件同步清理，退出后迟到的异步确认不能重新保存正文。未确认任务/消息在手动重试时复用请求 ID；连接断开后不把聊天/鼓励加入自动发送队列。
- 任务默认 PRIVATE；用户逐项切换 PUBLIC 后，服务端公共快照才包含该标题。切回私有后，完整新快照立即替换客户端公开列表。断线时隐藏公开列表，恢复读取最新权限快照。任务私有标题不进入公共消息、鼓励事件、历史累计或日志。

已公开并被他人看见的内容无法撤回对方的记忆、截图或自行复制；隐私切换负责停止之后的服务端分发和受控客户端显示。

## 学习统计口径

| 指标 | 口径 |
| --- | --- |
| 个人有效专注 | 复用 PresenceInterval 与 FOCUS PhaseInterval 的交集，合并同一人的重叠区间 |
| 本轮有效专注 | 个人交集限定当前 roundNo；Break 中不继续增加 |
| 本轮完成 | 首次完成发生在当前轮、当前仍完成且未删除的任务数量；Break 内完成归当前轮，Lobby 完成归 0，不算专注轮成果 |
| 取消/重复完成 | 取消扣除当前完成数；重新完成恢复当前状态，但首次轮次不变，不新增完成次数，不挪到后续轮 |
| 删除 | 移除任务及其当前完成贡献，不计入本轮或整场；结束后禁止修改，已结算值冻结 |
| 房间总体进度 | 整个 Session 所有未删除任务的完成数/总数，包括已离开成员；零任务显示未设置 |
| 房间共同专注 | 按用户合并有效 Focus 区间，再按起止边界扫描至少两名用户同时参与的时间并集；三人重叠仍只算一份，不简单相加个人时长 |
| 历史累计 | 本人 StudyRecord 的正式场次汇总；45/15 秒场次标演示并排除，DEMO_MODE 开关本身不把所有正常节奏记录都变成演示 |

新增 Task.firstCompletedRound 只记首次完成归属，不写完整行为日志；任务反复编辑/勾选不产生次数膨胀。本轮任务细节对迁移前场次整体标记未知，不用已有 completedAt 猜测历史首次轮次。原始阶段、参与区间足以计算的旧个人/共同专注仍可复用；没有原结算的旧场次明确显示不可还原。

## 聊天与低干扰反馈

快照附带当前 Session 最近 24 小时最多 50 条消息，服务端按 createdAt、id 稳定排序，查询本身即过滤到期内容，沿用原清理作业与过期回执。订阅和快照仍由现有串行队列协调；客户端将 HTTP、实时快照、命令确认和单条事件按消息 ID 合并、排序、限量、清理过期项，定期同步可填补实时遗漏。不提供更早分页回放。

阅读旧消息不强制滚动到底，显示「有新消息 · 回到最新」；在底部时继续跟随。发送失败保留草稿，显示重试操作；服务端保持每账号每 2 秒一条，客户端成功后暂禁发送。确认超时不自动重发聊天。

提供 🌱、💪、☕ 三种鼓励，服务端按账号每 10 秒一条（跨房间/标签页），客户端短暂冷却。事件无声、最多展示 4 秒、每人保留一条。任务首次完成广播不含标题的 ✓ + 昵称图标；不回放历史反馈。服务端事件 ID 与原请求 ID 对应，重复命令不重复广播；客户端再次按 ID 去重，快照与历史恢复不触发动画，尊重减少动态效果偏好。

## 具体限制

保持单实例 SQLite、每房 8 人、单房一次 Session、无房主转移。偏好不跨设备；草稿限当前标签页 24 小时，存储被禁用时仅当前页面可保留。聊天恢复只覆盖最新 50 条及 24 小时内；离线期间更多旧消息不承诺补齐。共同时长是参与区间指标，不证明真实注意力；原重启保守心跳统计边界继续有效。

未实测公网 HTTPS、Safari/iOS、实体低端手机及物理断电；未执行公网发布或替换用户的公网启动脚本。本阶段本轮首次完成不提供完整行为日志或历史轮次明细页。
