## 已有能力与本次增量

开始时已具备账号与房间、多人节奏、任务聊天、持久化 Summary、刷新重连、事务幂等结算、房主宽限期、同源静态服务、迁移和环境示例、3D/雨声及降级。沿用这些模块，本次补齐：

- 成员 `reconnectDeadlineAt` 持久化：服务重启时原在线成员获得恢复宽限，已断线成员沿用截止时间；反复重启不续期。超时按截止时间结束，数据库或调度暂时不可用也不延长统计终点。
- 复用原个人参与区间，按最后持久化心跳关闭旧区间；恢复后重新确认在线。阶段边界批量写入，长停机期间跨越多轮也保持原时间轴。
- 断线写失败保留待补偿记录，后续调度或重连先完成旧区间关闭。临时数据库错误与真正的鉴权失效、成员移除分开处理，避免假离线身份和永久在线记录。
- 页面同步失败保留快照和输入，可手动重试，也会重新连接和对齐；数据库写失败显示明确原因。确认失败的操作在同页重试时复用原请求 ID，避免已提交任务或消息被再次创建。
- Summary 登录回跳和读取重试、登录回房、结束后创建下一间房及离开后再次加入的导航闭环；避免认证刷新暂时失败卸载已打开房间。保持现有布局与视觉风格。
- 生产入口明确设置生产模式并检查构建产物；HTML 可更新、带哈希资源长期缓存，缺失音频/脚本返回 404。Vite 代理端口读取集中配置。
- `db:deploy` 应用增量迁移并创建自定义持久目录；`demo:init` 显式创建随机密码普通用户，同名账号跳过；`db:backup` 生成包含已提交 WAL 数据的一致性独立备份且不覆盖已有文件。
- 聊天和回执正文 24 小时清理；以过期回执阻止重新生成旧消息。活动房间保留幂等凭据，已结束房间及请求均超过 7 天后清理；保留账号、任务、阶段、参与区间和学习结果。
- 简洁 README、两至三账号短演示路线、备份恢复步骤、3D 与音频资源来源记录，以及随生产资源提供的 Three.js MIT 许可全文。

增量迁移：`prisma/migrations/202609080001_recovery/migration.sql`。增加成员恢复截止时间、凭据房间关联与聊天时间索引，回填旧凭据关联，不重建表或清空数据。

## 启动入口

项目根目录执行：

```powershell
npm ci
npm run setup
npm run build
npm start
```

默认生产访问 [http://localhost:3001](http://localhost:3001)。现有数据升级前先备份并停止旧进程，再执行以上命令。开发使用 `npm run dev`，访问 [http://localhost:5173](http://localhost:5173)。

演示前在 `.env` 设 `DEMO_MODE=true`，执行 `npm run demo:init`，保存打印的三组独立随机密码。详细配置、备份与恢复步骤见根目录 README。

## 未验证项与具体限制

未验证公网域名、HTTPS 反向代理、真实断电/磁盘损坏、实体低端手机及 Safari/iOS；没有公网部署目标，未购买或发布任何服务。数据库故障采用可恢复的真实写失败注入，不宣称能修复物理介质损坏。

MVP 保持单进程、本地 SQLite、每房最多 8 人、每房一次 Session；不转移房主，无聊天历史补发和个人历史列表。进程异常终止保守关闭个人区间，通常最多少计最后约 15 秒未持久化心跳间的专注，不把停机时间计入。未保存草稿和待确认请求在当前页面中保留，手动刷新或离开页面会清除。长期记录由部署者备份保留。

上述边界不阻断已验证的桌面浏览器多人 MVP、局部移动布局和可部署单实例交付。3D 不可用可使用既有座位卡片继续共学；移动系统可能暂停后台音频。
