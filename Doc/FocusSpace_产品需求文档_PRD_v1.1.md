# 2026-09-10 增补：学习成长与装扮闭环（当前有效范围）

本阶段由用户明确授权，覆盖本文原有「不做货币 / 装扮」及「全部免费」的旧限制。产品主流程为：设定目标 → 服务端记录有效专注 → 结束后获得经验与学习币 → 永久获取装扮 → 装备到个人空间 → 继续独自学习或邀请朋友。

- 经验只积累，不消耗，不因缺席、中断、AFK 降级。等级为 `1 + floor(sqrt(经验 / 100))`，Lv.2 需 100，Lv.3 需 400。等级开放获取资格，收费物品仍须兑换，零价格等级物品须领取。
- 初始 v1：每整分钟有效专注 2 经验 / 1 币；完整轮次 5 经验 / 2 币，次数上限为本场有效秒数除以 1500 取整。开始前设定的目标在结束前完成，且有效专注至少 300 秒，每日一次 5 经验 / 2 币。与他人有效重叠至少 300 秒，每日一次 5 经验 / 2 币。目标及共学分别限一次，以北京时间结算日计；多人、多任务、重复勾选不增加次数。
- 每场不足一分钟的余数不计奖。无每日签到、随机抽取、强制分享、充值、转账、支付、交易、收益倍率或排行榜。学习币仅供永久兑换，不具备兑现或流通能力。
- 本場共学结束时统一结算，成员提前离开保留参与区间，房主接任不改变这条规则。断线、重启按持久化有效心跳截断；未结算前首页不会显示已到账。Focus 不弹出奖励，Break 说明结算时机，结束 Summary 显示到账 / 处理中。
- 新建 Session 固定规则快照；升级前历史和升级时已经存在的 Session 不追溯。45/15 演示 Session 无正式奖励。演示奖励只能在单独创建的本地演示数据库中展示，不提供生产刷币接口。
- 目录覆盖服饰、配件、家具、房型、灯光、休息动作、环境音、鼓励表现；均复用程序化卡通低模、现有录音和稳定 ID。5 币「陶红开衫」「一束小花」提供第一次可达兑换目标。
- 用户可按类别和获取状态筛选、预览、兑换 / 领取、使用、卸下恢复基础。拥有权与装备独立；所有装备保存由服务端检查。已有共学空间使用创建时快照，个人空间更新用于下次共学。
- 管理员可以修改已实现资产的价格、最低等级、启用 / 下架 / 停用状态，发布新规则，查询用户资产和奖励 / 兑换流水。补发、币纠错和资产补发必须填写原因，并同时创建补偿流水及审计。经验不提供负向纠错。基础角色、头像、空间、聊天、普通鼓励及鸟鸣 / 雨声 / 炉火始终可用。
- 普通下架不剥夺已拥有资产。问题资产停用后保留拥有权、显示基础替代，不破坏房间加载；重新启用可继续装备。

详细操作与验收记录见 [学习成长与装扮交付](阶段交付_学习成长与装扮.md)。以下原文保留作历史设计参考，冲突处以上述增补为准。

# FocusSpace 个人空间升级产品需求

版本 v1.1 · 2026-09-09。本阶段是对 v1.0 PRD 的明确扩展；本文件优先于旧文档中的范围限制。v1.0 Word 保留为历史基线，v1.1 以本 Markdown 为当前增量版本。原计时、结算和成员授权规则继续生效。

## 现有能力与本阶段目标

已实现并保留账号、公开和私有共学、房间码与邀请链接、主持转交和异常接任、任务及公开级别、休息聊天、轻互动、学习反馈、个人历史、恢复、后台管理和个人声音偏好。未实现的访客登录、预约下一轮、好友/私聊、成长与兑换，不作为本阶段依赖。

本阶段让每位用户拥有长期保存的角色与个人自习室。用户在首页进入「个人空间」，先预览再保存；发起共学时使用自己的空间接待其他成员。基础资产全部免费。

## 三种对象的关系

| 对象                   | 生命周期             | 归属与用途                                                                             |
| ---------------------- | -------------------- | -------------------------------------------------------------------------------------- |
| 个人空间 PersonalSpace | 随账号长期保存       | 账号专属配置；只允许本人编辑；结束共学不会删除                                         |
| 共学房间 Room          | 一次接待             | 创建时复制发起人的空间、稳定种子和版本，所有成员看到相同快照；ownerId 只表示当前主持人 |
| StudySession           | 一次学习活动，可多轮 | 仍与 Room 一对一，承载原有计时、任务、聊天和结算；ENDED 后新建下一场                   |

修改个人空间用于下一次创建。转交主持权只改变主持权限，不能转移空间归属，也不能换成接任者的空间。本阶段新房间创建即冻结布置，包括大厅；旧房间保留原有大厅主题切换能力。

## 账号头像与首次设置

账号头像和 3D 角色独立。默认头像沿用 lake、sage、lilac、sun；个人资料支持上传静态 PNG、JPEG、WebP，最大 2 MB、1600 万像素。服务端必须实际解码并重新生成 256×256 PNG，不接受外部地址、任意文件、SVG 或动画；不能仅相信扩展名和 MIME。

注册成功后自动登录进入简短首次设置，可选择基础搭配、风格并实时预览，然后保存进入首页。可以跳过，跳过结果长期保存；之后从个人空间修改。通过邀请注册后可返回原房间码邀请。账号头像在个人资料中维护，不进入复杂装扮步骤。

## 角色与自习室

角色提供三种肤色、三种发型、三种发色、四种服装配色、四种配饰；长期保存，进入其他人的房间仍携带本人形象。保存角色后同步给当前活动房间成员。

角色状态沿用 JOINED、READY、FOCUSING、BREAKING、AFK、DISCONNECTED、ENDED。坐姿和桌椅使用统一尺寸，动作平滑过渡，呼吸/书写使用用户稳定种子错开。AFK 保留座位、隐藏角色；断线显示半透明角色及文字；结束回到安静的致意姿态。

自习室提供两种房型、三种风格、两种桌子、两种椅子、两种灯光。桌面、墙面、窗边、地毯区各两种搭配。槽位只能选择对应类别，全部布置预留八个学习座位。支持实时预览、保存、取消、恢复默认；默认恢复需保存才生效。保存失败保留当前草稿，多页面版本冲突明确提示，用户可以选择载入服务器版本。

所有 3D 场景、家具、角色与动作由 Three.js 生成。视觉为温暖安静的卡通低模：有厚度的木材、圆润衣袖、软垫座椅、陶杯、书页、低模植物、柔和天光与阴影；无外部人物模型或生成图片。固定镜头提供完整微缩书屋构图，移动端保留房间与座位状态；小屏使用简短座号，完整姓名/状态见成员列表。

## 共学与声音规则

沿用现有房间码、邀请链接和已实现的公开房间加入，不建立永久访客体系。每人环境音和音量独立，默认不播放。空间推荐只提供建议，不能自动替成员选择或播放声音。结束 Session 后保留空间与历史，下次创建复制最新已保存布置。

## 验收与后续

定向验收覆盖首次设置保存/跳过、编辑保存与失败保留、默认与取消、严格配置校验、图片真实解码、八人快照一致、主持转交、跨房间形象、旧数据迁移、七种状态、重连与移动端。生产构建及各工作区类型检查必须通过。

下一阶段成长与兑换复用本阶段稳定资产 ID；本阶段没有积分、背包、兑换入口、自由拖拽、碰撞编辑器、复杂捏脸或高级骨骼编辑。资产扩展须保持旧 ID 和生成版本可读。

## v1.2 增量：计划、统计与排行榜（2026-09-10）

导航栏提供待办清单、数据统计和排行榜。待办拥有高/中/低优先级、截止日期、最多八个标签、可选日程区间、父子层级，以及不重复、每日、每周三种重复方式。重复项在原项首次由未完成变为完成时生成下一实例；取消后再次完成视为新的完成转换。删除父待办同时归档其子树。

用户可以把一个或多个未完成待办加入自己的当前房间。房间任务保存待办 ID，标题、属性和层级在加入时复制，之后两端的完成状态双向同步；同一待办在同一场次只能加入一次。房间内也可直接建立带优先级、截止日期、标签和上级任务的任务。场次结束后房间任务冻结，待办继续保留。

数据统计只采用服务端结算的正式 StudyRecord，提供日、周、月专注趋势、任务完成情况、标签分布、上一周期对比及近十二周热力图。结束总结和历史记录展示本场任务及标签分析。单个任务的专注时间为本场有效专注在本场任务间的说明性均分，不声称精确追踪到单个任务。

排行榜提供自然周有效专注时长和当前成长等级两类榜单。演示场不进入榜单；封禁用户不显示。排行榜不发放收益，不影响结算或管理权限。

房主创建或在大厅配置节奏时可选 1、2、3、4、6、8、12 轮或无限轮。固定轮数在最后一轮 Focus 的服务端结束时间自动结束并结算；无限轮继续 Focus/Break 循环，直至房主或管理员结束。
