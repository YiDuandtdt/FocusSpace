# FocusSpace

各自学习，一起专注。根据 `Doc/FocusSpace_产品需求文档_PRD_v1.0.docx` 和 `Doc/FocusSpace_开发设计文档_v1.0.md` 实现的多人共学应用。

当前交付：**沉浸式共学空间**。在账号、成员同步、共享 Focus/Break 节奏、私有任务、休息聊天和持久化结果基础上，已接入 Three.js 窗边自习室、八席状态角色和个人雨声。3D 只展示已有服务端业务状态，统计口径保持不变。

## 启动

需要 Node.js **22.12+（推荐 24 LTS）** 和 npm。无需额外安装数据库服务。以下命令均在项目根目录执行：

```powershell
npm ci
npm run setup
npm run dev
```

打开 **[http://localhost:5173](http://localhost:5173)**。开发模式启动共享类型编译、Express（3001）和 Vite（5173），Vite 将 `/api` 和 `/socket.io` 代理到服务端。首次启动使用同一个主机名访问；`localhost` 与 `127.0.0.1` 的 Cookie 不共享。

`setup` 会复制不存在的 `.env`、生成 Prisma Client、创建 SQLite 文件、应用已有迁移并构建共享包。重复执行保留已有配置和数据。首次依赖下载需要网络；应用运行不需要外部服务、字体或图片。

从一期升级：先停止本项目正在运行的开发服务，再运行 `npm run setup` 和 `npm run dev`。本次迁移只新增 5 张表，不重建旧表、不清空已有账号或房间。Windows 下若 Prisma 报 `query_engine-windows.dll.node` 的 EPERM，说明旧服务仍占用引擎，停止旧服务后重新执行 setup。

快速演示：在 `.env` 增加 `DEMO_MODE=true` 并重启服务，房主在房间的「我们的节奏」点击「使用 45/15 秒演示节奏」。正常模式仍限制专注 1–180 分钟、休息 1–60 分钟。演示开关只开放该固定秒级预设，页面明确标注，改节奏仍会清除全员准备。

从第二阶段升级：停止旧开发服务，执行 `npm ci`、`npm run setup`、`npm run dev`。第三阶段仅新增前端依赖与静态资源，**没有数据库迁移**，保留现有账号、房间、任务和结果。雨声 WAV 已随项目提供，无需额外下载或生成；需要重建时执行 `npm run audio:generate`。

生产构建、单进程同源运行：

```powershell
npm run build
npm start
```

打开 **[http://localhost:3001](http://localhost:3001)**。同一 Express 进程提供网页、HTTP API 和 Socket.IO，直接刷新 `/rooms/:roomId` 可恢复页面。3001 被占用时，先停止已有开发服务；修改端口后也需同步 `.env` 的 `APP_ORIGINS`，开发代理目标在 `apps/web/vite.config.ts`。

## 体验路径

1. 打开 `/register`，填写账号、昵称、密码和基础形象。注册成功后进入 `/login` 登录。
2. 首页创建房间，选择 25/5、50/10 或自定义分钟数，复制 6 位房间码。
3. 用另一浏览器、独立浏览器配置或无痕窗口注册第二个账号，输入房间码加入。普通标签页共享登录 Cookie，不能用于模拟两个账号。
4. 两端分别添加个人任务。只有自己能看到标题；另一端看到任务完成数量与比例。修改节奏后所有成员重新准备，房主也须在线、非暂离且准备。
5. 房主点击「开始共学」，两端进入同一轮 Focus。完成、取消完成、编辑和删除任务，观察另一端进度实时变化；尝试聊天，输入区保持锁定。
6. 服务端到期自动进入 Break，聊天室展开。发送文字消息，另一端立即看到；每条最多 500 字，每用户每 2 秒一条。15 秒演示休息结束后，两端自动进入第 2 轮 Focus，输入区收起。
7. 在 Focus 中刷新、切回前台、暂离/回来或关闭同账号的一个标签页，观察轮次与倒计时恢复。普通成员离开再加入会复用任务；迟到、暂离和断线只影响个人统计，不暂停全房节奏。
8. 房主点击「结束共学」并确认，两端展示个人有效时长、完整轮次、任务完成率和共同专注人数。点击「打开已保存结果」后刷新，结果保持不变。房主断线超时也会自动结束并结算。

没有默认账号、固定房间码或样例数据，正常注册即可体验。一个房间对应一次 Session，结束后需新建房间继续共学。

第三阶段体验入口就是现有 `/rooms/:roomId`：建房或从首页继续当前房间即可看到「窗边自习室」。四种头像对应耳机、嫩芽帽、贝雷帽和鸭舌帽；准备时举手，专注时伏案书写，休息时伸展，暂离为空座，断线则半透明保留座位。所有座位都有编号、昵称和文字状态。点击「播放雨声」后可暂停、拖动音量；其他成员的声音不受影响。手机顶部的「空间与计时 / 我的任务 / 休息聊天」可直接跳到操作区。

「使用座位卡片」可主动关闭 3D；WebGL 不可用、加载超时、脚本加载失败或上下文丢失时也自动显示八席卡片。「重试 3D」重新创建场景，业务计时和任务不重置。

## 数据与配置

默认数据库位于 **`prisma/data/focusspace.db`**；`.env` 与数据库已被 Git 忽略。SQLite 启用 WAL，数据持久化不依赖浏览器存储。停止应用后备份整个 `prisma/data` 目录；运行期间不要仅复制主文件而遗漏 WAL。

| 环境变量              | 默认值 / 用途                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------ |
| `DATABASE_URL`        | `file:./data/focusspace.db`，相对 `prisma/schema.prisma`；部署时可使用持久化目录的绝对路径 |
| `HOST` / `PORT`       | `127.0.0.1` / `3001`                                                                       |
| `APP_ORIGINS`         | 允许的浏览器来源，逗号分隔，开发与本地生产端口已配置                                       |
| `COOKIE_SECURE`       | 本地 HTTP 为 `false`；HTTPS 部署设为 `true`                                                |
| `SESSION_DAYS`        | 登录有效期，默认 7 天                                                                      |
| `DISCONNECT_GRACE_MS` | 断线宽限期，默认 60000 毫秒                                                                |
| `DEMO_MODE` | 默认 `false`；设为 `true` 后房主可选择 45/15 秒演示节奏 |

当前按设计采用**单服务进程、本地 SQLite**，进程内串行写队列同时保护房间状态和跨房间成员唯一性，不启动多个副本共享此数据库。HTTPS 反向代理需转发 Socket.IO WebSocket Upgrade，并在 `APP_ORIGINS` 中填写实际网页来源。对外监听时显式配置 `HOST=0.0.0.0`。

新增数据库修改使用 `npm run db:migrate -- --name <名称>`，提交 `prisma/migrations`。查看本地数据使用 `npm run db:studio`。

## 验证

```powershell
npm run typecheck
npm run build
npm run test:flow
npm run test:session
npm run test:space
```

`test:flow` 自动生成 `.tmp/flow-*` 隔离数据库、选择空闲端口并启动测试服务器，不修改日常数据库。验证注册登录、来源限制、房间事务/幂等、隐私权限、容量、并发跨房间加入、Ready/AFK/节奏/资料广播、多标签页、断线恢复、退出撤销、重启恢复和房主超时结束；随后用两个独立浏览器上下文跑完整页面链路，并保存桌面及移动端截图。超时验证仅在测试服务中使用 3 秒宽限期。

Windows 自动使用已安装的 Microsoft Edge。没有该路径的机器先运行 `npx playwright install chromium`。验证结束自动停止测试服务器；截图和隔离数据保留在 `.tmp`，不会提交到 Git。

`test:session` 同样使用隔离数据库：验证任务所有权与公开快照隐私、多标签页版本冲突、准备/房主权限、阶段追赶、AFK 和在线区间、聊天边界与限频、服务重启、冻结与重复结束、确定性的统计口径；随后用桌面和移动端两个浏览器完成真实 45/15 秒轮转、任务同步、刷新、系统时钟偏移、纯文本聊天及持久化结果。浏览器部分约需一分钟。

`test:space` 使用独立 `.tmp/space-*` 数据库和生产构建：八人入座及跨端映射、角色姿态、AFK、断线与刷新重连、空座补入、雨声真实播放进度/循环/音量/暂停、隐藏与减少动态效果时停止渲染、WebGL 上下文丢失及资源释放、脚本加载失败、无 WebGL、音频失败、降级后的任务/计时/Break 聊天和离开页面清理。保存桌面、390px 移动端和降级截图。测试前先执行 `npm run build`。

## 资源来源

家具与角色为本项目代码生成的几何体，无外部模型、贴图或字体。Three.js 采用 MIT 许可。`apps/web/public/audio/window-rain.wav` 为原创程序合成雨声（24 秒、24 kHz、16 bit 双声道、约 2.3 MB），生成脚本和音频均以 CC0-1.0 提供，不包含第三方录音采样。来源、许可和重建方式见 [音频资源说明](apps/web/public/audio/SOURCES.md)。应用运行不需要第三方资源服务。

## 限制与后续

- 维持单服务进程、SQLite 和全局串行写队列；每房最多 8 人，无多实例调度或跨进程广播。
- 任务标题固定私有，最多 200 字、每人每次 Session 最多 100 个任务；不提供标题公开开关。
- 聊天成功后持久化，但不提供历史查询或断线补发；浏览器最多展示当前连接收到的最近 100 条。发送确认超时会保留草稿，不自动补发。
- 仅提供本次 Session 的个人结果，不提供历史列表、排行榜和房间总体共同专注时长。大厅结束结果为零时长，仍保存任务最终计数；升级前已结束的旧大厅房间以零统计兼容显示。
- 房主断线默认保留 60 秒，超时结束，不转移房主。异常退出以最后持久化的有效心跳关闭个人区间，停机时间不计专注；完整轮次要求不中断地参与整个 Focus。
- 一个固定自习室和四种几何体角色；不提供多主题、自由移动、碰撞、GLB 模型或高级角色定制。长昵称在 3D 标签中省略，完整昵称可在成员列表或座位卡片查看。
- 3D 需要 WebGL 2；不支持时使用卡片。尚未在实体低端手机、Safari/iOS 上做性能或音频兼容性实测，不承诺所有设备稳定达到 30 FPS。
- 仅一种程序合成雨声，不是自然录音；音量和播放偏好不持久化，刷新后默认关闭。隐藏页面只暂停 3D，主动播放的雨声继续；移动系统仍可能暂停后台音频。
